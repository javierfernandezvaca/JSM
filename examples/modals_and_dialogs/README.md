# Modals and Dialogs

Aplicación sencilla que utiliza JSM para manejar la apertura y cierre de `modales y diálogos`, permitiendo a los usuarios interactuar con diferentes tipos de elementos emergentes en la interfaz de usuario.

## Conceptos JSM Demostrados
- Sistema de diálogos JSM (`JDialog`)
- Gestión de estado simple
- Arquitectura limpia

## Cómo Ejecutar
1. Asegúrate de tener Flutter instalado
2. Clona el repositorio
3. Navega al directorio del ejemplo
4. Ejecuta `flutter pub get` para instalar dependencias
5. Ejecuta `flutter run` para iniciar la aplicación

## Características
- Muestra diferentes tipos de diálogos modales
- Demuestra la gestión de estado para controlar la visibilidad de diálogos
- Implementa la arquitectura limpia para separar la lógica de negocio
