# Reactive State Counter

Aplicación clásica del contador que utiliza la **gestión de estado reactiva** haciendo uso del sistema de `observables` y `observadores` de JSM.

## Conceptos JSM Demostrados
- Estado reactivo con observables y observadores
- Patrón de arquitectura limpia
- Separación de responsabilidades

## Cómo Ejecutar
1. Asegúrate de tener Flutter instalado
2. Clona el repositorio
3. Navega al directorio del ejemplo
4. Ejecuta `flutter pub get` para instalar dependencias
5. Ejecuta `flutter run` para iniciar la aplicación

## Características
- Implementación de un contador reactivo
- Actualización automática de la UI cuando cambia el estado
- Ejemplo de arquitectura limpia con JSM
