# Simple State Counter

Aplicación clásica del contador que utiliza la **gestión de estado simple** haciendo uso del método `update()` y `JBuilderWidget` de JSM.

## Conceptos JSM Demostrados
- Gestión de estado simple con `update()`
- Uso de `JBuilderWidget`
- Arquitectura limpia

## Cómo Ejecutar
1. Asegúrate de tener Flutter instalado
2. Clona el repositorio
3. Navega al directorio del ejemplo
4. Ejecuta `flutter pub get` para instalar dependencias
5. Ejecuta `flutter run` para iniciar la aplicación

## Características
- Implementación de un contador simple
- Actualización manual de la UI con `update()`
- Ejemplo de arquitectura limpia con JSM
