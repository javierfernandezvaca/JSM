# Tic Tac Toe

Juego de Tic Tac Toe que utiliza la **gestión de estado reactiva** y el patrón de diseño MVVM (Model-View-ViewModel) de JSM. Esta aplicación permite a los usuarios jugar al Tic Tac Toe con una interfaz de usuario reactiva que se actualiza automáticamente en respuesta a los cambios de estado.

## Conceptos JSM Demostrados
- Patrón MVVM (Model-View-ViewModel)
- Estado reactivo con observables
- Separación de responsabilidades

## Cómo Ejecutar
1. Asegúrate de tener Flutter instalado
2. Clona el repositorio
3. Navega al directorio del ejemplo
4. Ejecuta `flutter pub get` para instalar dependencias
5. Ejecuta `flutter run` para iniciar la aplicación

## Características
- Juego completo de Tic Tac Toe
- UI reactiva que se actualiza automáticamente
- Implementación del patrón MVVM
- Gestión de estado del juego
