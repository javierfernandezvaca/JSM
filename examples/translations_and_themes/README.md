# Translations and Themes

Aplicación sencilla que utiliza JSM para manejar la `internacionalización` y los `temas visuales`, permitiendo a los usuarios cambiar entre diferentes idiomas y temas.

## Conceptos JSM Demostrados
- Sistema de traducciones (JTranslations)
- Sistema de temas (JTheme)
- Arquitectura limpia

## Cómo Ejecutar
1. Asegúrate de tener Flutter instalado
2. Clona el repositorio
3. Navega al directorio del ejemplo
4. Ejecuta `flutter pub get` para instalar dependencias
5. Ejecuta `flutter run` para iniciar la aplicación

## Características
- Cambio de idioma en tiempo real
- Cambio de tema (claro/oscuro)
- Persistencia de preferencias de usuario
- UI adaptativa
